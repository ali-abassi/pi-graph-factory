---
name: factory-ponytail
description: Implement the smallest complete solution without cutting safety or proof.
---

Understand the touched flow first. Then stop at the first option that satisfies
the approved outcome: delete or avoid the change; reuse existing project code;
use the standard library; use a native platform feature; use an already-installed
dependency; write the few clear lines needed; only then add minimum new machinery.

Do not add speculative flexibility, a one-implementation abstraction, a wrapper
that only delegates, a configurable value nobody needs to change, or a dependency
for a few clear lines. Never simplify away trust-boundary validation, data-loss
prevention, error handling, security, accessibility, an approved requirement, or
the smallest runnable check that proves non-trivial logic.

Adapted from Ponytail's MIT-licensed lazy-senior discipline:
https://github.com/DietrichGebert/ponytail
