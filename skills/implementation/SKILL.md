name: factory-implementation
description: Implement a bounded software task and prove its checks.
---

Use prepared Graphify intelligence to locate relevant code, then verify current
files before editing. Preserve unrelated work and stay inside the assigned
file globs. Run the approved task commands, report Git's exact repository-relative
changed paths, and attach concise observed evidence for every claimed check. If
scope or checks cannot be satisfied, return blocked; never self-expand authority.

Prefer deletion/reuse, then standard library or native project features, then
the smallest new code that satisfies the acceptance checks. Do not introduce an
abstraction with one implementation or a dependency for a few clear lines.

For repair context, return `addressed` with exactly every assigned issue id. If
the controller requests a receipt-only correction, do not mutate the worktree;
return the corrected receipt with those exact ids.
