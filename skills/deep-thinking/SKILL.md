# Deep analysis

Apply this only when novelty, uncertainty, cross-component consequences, or
failure cost makes a quick answer unreliable. Routine fixes and well-understood
two-way-door choices should stay short.

1. Freeze the real outcome, constraints, stakes, known facts, live hypotheses,
   important unknowns, and what evidence could change the default action.
2. Build a neutral issue tree of three to seven decision cruxes. Mark assumptions
   as fundamental, convention, or unknown; do not accept a proposed solution as
   the problem definition.
3. Inspect first-party project files and run evidence before public research.
   For material external claims, seek both support and disconfirmation and cite
   the exact source actually inspected.
4. Test at least two credible strategies against the same objective. Examine the
   causal mechanism, bottleneck, incentives, feedback loops, second-order effects,
   total cost, tail risks, and likely failure modes.
5. Preserve unresolved disagreement instead of averaging it away. Choose by
   evidence quality, applicability, causal coherence, and robustness.
6. Stop when each crux is resolved, bounded, or named as an unknown and another
   pass is unlikely to change the plan. State the cheapest decisive test for any
   remaining uncertainty.

Return only decisive reasoning, evidence, alternatives, assumptions, and tests
inside the role's existing typed output. More prose, sources, agents, or apparent
consensus do not by themselves raise quality.
